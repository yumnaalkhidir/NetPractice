# NetPractice

Solved configuration answers for the 42 School NetPractice exercise: a series of network topologies where IP addresses, subnet masks, and gateways must be assigned correctly so every host can reach every other host.

This isn't a coding project — each `levelN.json` file is an exported answer set (interface IPs and routes) for one of the 10 topology levels.

## Concepts covered
- IPv4 addressing and subnet masks
- Routing and default gateways
- Network topology troubleshooting

## Contents
`level1.json` – `level10.json`, one exported answer set per topology level.
